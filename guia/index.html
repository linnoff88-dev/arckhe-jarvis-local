Em resumo

O Jarvis Local é um kit aberto para montar um assistente pessoal que você chama pela voz ("Jarvis, …") e que roda inteiro no seu computador. Ele responde a partir das suas próprias anotações, mostradas numa galáxia 3D, fala com uma voz clonada e anota coisas novas quando você pede. Serve para quem quer um assistente sem mensalidade e sem mandar o áudio para a nuvem. Você precisa de uma máquina com GPU (placa NVIDIA, Mac com chip da Apple ou mini PC de memória unificada) e do Claude Code ou do Codex para construir, uma vez, com os 8 prompts do kit.

O que é

Três motores abertos e oito prompts

O kit instala os três motores gratuitos e entrega os prompts que fazem o Claude Code (ou o Codex) construir o assistente em cima deles. Depois de pronto, ele roda sem os dois e sem internet.

🧠 Cérebro

O Ollama roda um modelo de IA aberto (Qwen, Gemma, gpt-oss) na sua placa de vídeo e responde a partir das suas notas.

🗣️ Voz

O VoiceStudio clona a sua voz a partir de 10–20 segundos de gravação. O motor VoxCPM2 fala português.

👂 Ouvidos

O Whisper transcreve o que você fala ali mesmo. Você diz "Jarvis", ele escuta; diz "para", ele se cala.

Leia antes · requisito

Roda em GPU. Não em VPS comum.

Cérebro, voz e ouvidos ficam na memória ao mesmo tempo, e o cérebro é o maior. O que decide tudo é quanta memória o modelo enxerga: a VRAM da placa NVIDIA ou a memória unificada do Mac e dos mini PCs de IA.

✓ Roda bem

Mac com Apple Silicon (16 GB+, ideal 32 GB)
PC com placa NVIDIA (12 GB+ de VRAM, ideal 16–32 GB)
Mini PC de memória unificada (AMD Ryzen AI Max+, NVIDIA DGX Spark)

✗ Não serve para conversar por voz

VPS / servidor na nuvem sem GPU
Notebook de 8 GB sem placa de vídeo
Placa com menos de 12 GB de VRAM (só conversa simples)

Por que não numa VPS? Uma VPS comum tem 2–4 vCPU e 4–16 GB de RAM. Um modelo de 9B nem cabe em 4 GB, e na CPU responde a 2–5 palavras por segundo: lento demais para conversa. O instalador confere a sua máquina e para com uma explicação quando não acha GPU.

Qual cérebro para qual memória

Tamanho do download de cada modelo (4 bits, biblioteca do Ollama, 04/11/2026). O instalador escolhe sozinho até o gpt-oss:120b; o último da lista você escolhe com --modelo. Deixe ~30% livre: a voz e os dois Whisper ocupam, por estimativa, uns 4–6 GB a mais na mesma placa.

16 GBqwen3.5:9b · ~7 GB
24 GBgemma4:12b · ~8 GB
32 GBqwen3.8:27b · 18 GB
64 GBgemma4:31b · ~20 GB
96–128 GBgpt-oss:120b · 65 GB
128 GB+qwen3.5:122b-a10b · 81 GB · à mão

Também cabem: gpt-oss:20b (14 GB, rápido), gemma4:26b-a4b (16–19 GB), llama4:scout (67 GB). Tags terminadas em -cloud rodam na nuvem do Ollama: o instalador recusa. Tabela completa em MODELOS.md.

Como funciona

Uma conversa, do microfone à resposta

Tudo acontece na sua máquina, em portas locais. O prompt 07 mede quanto cada etapa leva no seu computador.

🎙️ "Jarvis, …"→ 👂 Whisper transcreve→ 🌌 busca nas suas notas→ 🧠 Ollama responde→ 🗣️ VoiceStudio fala na sua voz

Ollama · porta 11434

Servidor de modelos abertos no formato compatível com OpenAI. O mesmo código fala com outro endpoint trocando três campos.

VoiceStudio · porta 3900

Motor de voz local. O assistente fixa o motor a cada início para nenhuma licença trocar sem aviso.

Painel · porta 4700

A galáxia 3D das notas no navegador, presa em 127.0.0.1. É por ele que você fala e vê de qual nota veio a resposta.

Termos em uma linha

Tag

O nome do modelo no Ollama, com o tamanho: qwen3.5:9b.

4 bits

Modelo comprimido para caber em menos memória, com pouca perda de qualidade.

Endpoint

O endereço que recebe as perguntas, aqui localhost:11434/v1.

VRAM / memória unificada

A memória que a GPU usa. No Mac e nos mini PCs de IA, é a mesma do sistema.

CDN

Servidor de arquivos na internet. O prompt 08 traz as bibliotecas para dentro do projeto.

3d-force-graph

Biblioteca aberta que desenha a galáxia 3D das notas no navegador.

Pré-requisitos

O que precisa ter antes

O instalador cuida dos três motores e confere o resto antes de começar: se faltar algo, ele mostra o comando para instalar.

GPU

Placa NVIDIA, Mac com chip da Apple ou mini PC de memória unificada (veja acima). Na NVIDIA, com o driver instalado: nvidia-smi tem de funcionar.

Python 3.10+ e curl

No Ubuntu/Debian também o python3-venv, e sudo para instalar o Ollama.

sudo apt install -y python3-venv curl

Chrome

Ou outro navegador com acesso ao microfone.

Claude Code ou Codex

Só para construir com os prompts, uma vez.

Guia de uso · passo a passo

Do zero ao "Jarvis, …"

Uma noite para instalar, um fim de semana para construir. Cada passo termina com uma prova.

1

Baixe o kit

Clone o repositório no computador onde o assistente vai morar.

git clone https://github.com/inematds/jarvis-local.git
cd jarvis-local
2

Simule a instalação

Mostra a GPU, a memória e o modelo que vai ser escolhido, sem instalar nada. Sem GPU, ele para e explica.

# Mac ou Linux
bash instalar/instalar.sh --simular
# Windows (PowerShell)
powershell -ExecutionPolicy Bypass -File instalar\instalar.ps1 -Simular
3

Instale os três motores

O mesmo comando sem a simulação: Ollama + o modelo da sua memória, Whisper (faster-whisper ou mlx-whisper) e VoiceStudio. Para escolher o modelo à mão: --modelo qwen3.8:27b.

bash instalar/instalar.sh                  # Mac ou Linux
bash instalar/instalar.sh --modelo gemma4:12b  # forçar um modelo
powershell -ExecutionPolicy Bypass -File instalar\instalar.ps1  # Windows

Na placa NVIDIA ele também instala as bibliotecas CUDA do Whisper (cuBLAS e cuDNN). No fim, grava em ~/.jarvis-local/minha-maquina.json a tag do cérebro e o Python que os prompts vão usar.

4

Crie a voz

No VoiceStudio: Model Catalogue → instale o VoxCPM2 (fala português, licença Apache-2.0) e selecione. Depois Profiles → New → Clone com 10–20 s da SUA voz, sem música nem eco, e dê o nome Jarvis. O VoiceStudio é um app com tela; anote a versão que funcionou e não atualize no meio do projeto. No Linux, abra com ~/.local/bin/VoiceStudio (é um AppImage: no Ubuntu 24.04 precisa de sudo apt install -y libfuse2t64, no 22.04 de libfuse2). No primeiro uso ele baixa o próprio motor e demora.

5

Verifique

Confere os três motores e mede a primeira resposta do cérebro na sua máquina.

python3 instalar/verificar.py
#  ✓ GPU: …   ✓ modelo baixado   ✓ respondeu em X s   ✓ VoiceStudio no ar   (exemplo)
6

Construa com os prompts

Abra o Claude Code (ou o Codex) numa pasta vazia e cole os prompts 01 → 08 em ordem, um por vez, esperando cada um terminar e se provar. No prompt 01, preencha a tag do cérebro e o Python com o que está em ~/.jarvis-local/minha-maquina.json.

mkdir ~/meu-jarvis && cd ~/meu-jarvis && claude
# cole o conteúdo de prompts/01-galaxia-e-cerebro.md
7

Meça e prove

O prompt 07 cria verificar_tudo.py, que mede ouvir · pensar · falar na sua máquina. O prompt 08 desliga o Wi-Fi e confere que a lista de conexões externas sai vazia.

python3 verificar_tudo.py
# ouvir 0,6 s · pensar 1,9 s · falar 0,8 s · total 3,3 s   (exemplo)
# 14 ok, 0 falha, 0 aviso
8

Use

"Jarvis, o que eu anotei sobre o cliente X?" · "Jarvis, anota que a reunião mudou para quinta." · "Muda para o grande." · "Tudo local."

Cuidados e próximos passos

Antes de colocar no dia a dia

O que o kit ensina a fazer certo, e para onde ir depois.

Voz
Clone só a sua vozOu a de quem autorizou. Clonar voz famosa para algo público é problema jurídico, não técnico.
Versões
Fixe modelo e motor"Latest" é como um assistente que funcionava quebra numa terça-feira. O config.json guarda a tag exata.
Nuvem
Opcional, e só quando você pedir"Muda para a nuvem" usa o CLI que você já assina (Claude Code ou Codex) ou um endpoint com a SUA chave. O padrão é local.
Depois
Um cérebro maior lado a ladoCom memória sobrando, ponha um modelo de 27B ou 120B na prateleira e pergunte as mesmas 5 coisas aos dois: a diferença mostra o que a memória extra compra.
