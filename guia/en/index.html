In brief

Jarvis Local is an open kit for building a personal assistant you call by voice ("Jarvis, …") that runs entirely on your computer. It answers using your own notes, displayed in a 3D galaxy, speaks with a cloned voice, and records new information when you ask. It’s for anyone who wants an assistant without a monthly fee or sending audio to the cloud. You need a computer with a GPU (an NVIDIA graphics card, a Mac with an Apple chip, or a unified-memory mini PC) and Claude Code or Codex to build it once using the kit’s 8 prompts.

What it is

Three open engines and eight prompts

The kit installs three free engines and provides the prompts that have Claude Code (or Codex) build the assistant on top of them. Once it’s ready, it runs without either tool and without internet.

🧠 Brain

Ollama runs an open AI model (Qwen, Gemma, gpt-oss) on your graphics card and answers using your notes.

🗣️ Voice

VoiceStudio clones your voice from 10–20 seconds of audio. The VoxCPM2 engine speaks Portuguese.

👂 Ears

Whisper transcribes what you say right there. Say "Jarvis" and it listens; say "stop" and it goes quiet.

Read first · requirement

Runs on a GPU. Not an ordinary VPS.

The brain, voice, and ears all stay in memory at the same time, and the brain takes up the most. What matters is how much memory the model can access: the NVIDIA card’s VRAM or the unified memory in a Mac or AI mini PC.

✓ Runs well

Mac with Apple Silicon (16 GB+, 32 GB ideal)
PC with NVIDIA graphics card (12 GB+ VRAM, 16–32 GB ideal)
Unified-memory mini PC (AMD Ryzen AI Max+, NVIDIA DGX Spark)

✗ Not suitable for voice conversations

VPS / cloud server without a GPU
8 GB laptop without a graphics card
Graphics card with less than 12 GB VRAM (simple chat only)

Why not a VPS? An ordinary VPS has 2–4 vCPUs and 4–16 GB of RAM. A 9B model won’t even fit in 4 GB, and on a CPU it responds at 2–5 words per second: far too slow for conversation. The installer checks your computer and stops with an explanation if it can’t find a GPU.

Which brain for how much memory

Download size for each model (4-bit, Ollama library, 11/04/2026). The installer automatically chooses up to gpt-oss:120b; choose the last one in the list with --modelo. Leave ~30% free: the voice and both Whisper engines are estimated to use about 4–6 GB more on the same card.

16 GBqwen3.5:9b · ~7 GB
24 GBgemma4:12b · ~8 GB
32 GBqwen3.8:27b · 18 GB
64 GBgemma4:31b · ~20 GB
96–128 GBgpt-oss:120b · 65 GB
128 GB+qwen3.5:122b-a10b · 81 GB · manual

Also fit: gpt-oss:20b (14 GB, fast), gemma4:26b-a4b (16–19 GB), llama4:scout (67 GB). Tags ending in -cloud run in the Ollama cloud: the installer refuses them. Full table in MODELOS.en.md.

How it works

A conversation, from microphone to reply

Everything happens on your computer, on local ports. Prompt 07 measures how long each step takes on your machine.

🎙️ "Jarvis, …"→ 👂 Whisper transcribes→ 🌌 searches your notes→ 🧠 Ollama responds→ 🗣️ VoiceStudio speaks in your voice

Ollama · port 11434

Open-model server with an OpenAI-compatible format. The same code can talk to another endpoint by changing three fields.

VoiceStudio · port 3900

Local voice engine. The assistant pins the engine at each startup so no license changes without notice.

Dashboard · port 4700

The 3D notes galaxy in your browser, bound to 127.0.0.1. You talk through it and see which note the answer came from.

Terms in a nutshell

Tag

The model name in Ollama, including its size: qwen3.5:9b.

4-bit

A model compressed to fit in less memory, with little loss in quality.

Endpoint

The address that receives questions, here localhost:11434/v1.

VRAM / unified memory

The memory the GPU uses. On Macs and AI mini PCs, it’s shared with the system.

CDN

An internet file server. Prompt 08 brings the libraries into the project.

3d-force-graph

An open library that draws the 3D notes galaxy in your browser.

Requirements

What you need beforehand

The installer handles the three engines and checks everything else before starting. If anything is missing, it shows you the command to install it.

GPU

NVIDIA graphics card, Mac with an Apple chip, or unified-memory mini PC (see above). On NVIDIA, with the driver installed: nvidia-smi must work.

Python 3.10+ and curl

On Ubuntu/Debian, you also need python3-venv and sudo to install Ollama.

sudo apt install -y python3-venv curl

Chrome

Or another browser with microphone access.

Claude Code or Codex

Only needed once, to build with the prompts.

User guide · step by step

From scratch to "Jarvis, …"

One evening to install, one weekend to build. Every step ends with proof.

1

Download the kit

Clone the repository on the computer where the assistant will live.

git clone https://github.com/~~ARCKHÉTDS~~/jarvis-local.git
cd jarvis-local
2

Simulate the installation

Shows your GPU, memory, and which model will be selected without installing anything. If there’s no GPU, it stops and explains why.

# Mac or Linux
bash instalar/instalar.sh --simular
# Windows (PowerShell)
powershell -ExecutionPolicy Bypass -File instalar\instalar.ps1 -Simular
3

Install the three engines

Run the same command without simulation: Ollama + the model that fits your memory, Whisper (faster-whisper or mlx-whisper), and VoiceStudio. To choose the model manually: --modelo qwen3.8:27b.

bash instalar/instalar.sh                  # Mac or Linux
bash instalar/instalar.sh --modelo gemma4:12b  # force a model
powershell -ExecutionPolicy Bypass -File instalar\instalar.ps1  # Windows

On an NVIDIA card, it also installs Whisper’s CUDA libraries (cuBLAS and cuDNN). At the end, it saves the brain tag and the Python interpreter the prompts will use to ~/.jarvis-local/minha-maquina.json.

4

Create the voice

In VoiceStudio: Model Catalogue → install VoxCPM2 (speaks Portuguese, Apache-2.0 license) and select it. Then go to Profiles → New → Clone with 10–20 seconds of YOUR voice, without music or echo, and name it Jarvis. VoiceStudio is a desktop app; note the version that worked and don’t update in the middle of the project. On Linux, open it with ~/.local/bin/VoiceStudio (it is an AppImage: Ubuntu 24.04 needs sudo apt install -y libfuse2t64, 22.04 needs libfuse2). On first launch it downloads its own engine, which takes a while.

5

Verify

Checks the three engines and measures the brain’s first response on your computer.

python3 instalar/verificar.py
#  ✓ GPU: …   ✓ model downloaded   ✓ responded in X s   ✓ VoiceStudio running   (example)
6

Build with the prompts

Open Claude Code (or Codex) in an empty folder and paste prompts 01 → 08 in order, one at a time, waiting for each to finish and prove itself. In prompt 01, fill in the brain tag and Python interpreter from ~/.jarvis-local/minha-maquina.json.

mkdir ~/meu-jarvis && cd ~/meu-jarvis && claude
# paste the contents of prompts/01-galaxia-e-cerebro.md
7

Measure and prove

Prompt 07 creates verificar_tudo.py, which measures listening · thinking · speaking on your computer. Prompt 08 turns off Wi-Fi and checks that the list of external connections is empty.

python3 verificar_tudo.py
# listen 0.6 s · think 1.9 s · speak 0.8 s · total 3.3 s   (example)
# 14 passed, 0 failed, 0 warnings
8

Use it

"Jarvis, what did I note about client X?" · "Jarvis, note that the meeting moved to Thursday." · "Switch to the large model." · "Keep everything local."

Care and next steps

Before using it every day

What the kit teaches you to do right, and where to go next.

Voice
Clone only your own voiceOr someone else’s, with their permission. Cloning a famous person’s voice for public use is a legal issue, not a technical one.
Versions
Pin the model and engine"Latest" is how an assistant that worked can break on a Tuesday. The config.json keeps the exact tag.
Cloud
Optional, and only when you ask"Switch to the cloud" uses the CLI you already subscribe to (Claude Code or Codex) or an endpoint with YOUR key. Local is the default.
